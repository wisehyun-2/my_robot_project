# v5 관절 조립 그림과 영상 (hip · 무릎 · 바퀴)

`export/WheelBiped_v5.f3d`(허브 버전 16, 기준 자세, 로봇 기준 부품 이름; 11-09에 버전 16으로 다시 만듦)를 Fusion의 저장하지 않는 새 문서로 가져와
관절 부품을 다시 새 문서로 복사하고, 분해 → 조립 단계별로 캡처한 그림과 영상이다. 양식은 v2의
`robot_cad_v2/manufacturing/explain/assembly/`와 같다. 설명용 그림이며 제작 도면이 아니다.
다리는 **오른쪽(`_R`, CAD +y)** 만 그렸다(왼쪽은 대칭). 허브 문서(`WheelBiped_v5`)는 바꾸지 않는다.

11-09 다시 만든 내용(버전 13~16 반영): 바퀴 허브 플랜지 핀 구멍 8.0(핀을 플랜지에 바닥까지 넣은 채 출력부로), 림 등록 홈 3.6, moteus 보드 나사 ④ M2.5 × 5, 바퀴 모터를 컵과 함께 55.3° 돌림(리드선 홈이 컵 리드선 홈과 같은 각도, ① 고정자 나사 39.7° + 60°k — 바퀴 단면 ②를 40°·160°로), hub 인서트 스피곳 1.2·컵/캡 인서트 구멍 +1 mm는 모델 형상 그대로.

각 폴더: `00_overview.png`(분해도), `NN_sK_a_before.png` / `NN_sK_b_after.png`(단계마다 조립 전·후, 빨간 화살표 = 이동 방향,
초록 라벨 = 방금 결합된 부품), `NN_done.png`(완성), 단면 2장(`*_cut1.png`, `*_cut2.png`), 영상(1920 × 1080, 30 fps,
왼쪽 Fusion 화면 + 오른쪽 단계 목록·설명·체결 부품, 아래 자막, 끝에 단면 2장).

- 색은 부품 구분용이다(허벅지 파랑, 정강이 초록, 컵 회색, 바퀴 허브 플랜지 주황, 림 연주황 — 실제는 검정 PETG).
  허벅지·정강이는 그 관절 쪽만 잘라 보였다. 배선·커넥터는 모델에 없다.
- 나사·와셔·핀·인서트는 **모델에 있는 것을 그대로** 복사해 하나씩 축을 따라 돌며 들어가게 했다. 모델에 없는 것만 BOM 규격으로
  그렸다: hub 인서트 플랜지 볼트 ⑥ ISO 10642 M3 × 16 12.9 × 6(r 18, 30° + 60°k, 인서트 면 → PETG 벽 6 → 받침 링 탭),
  무릎 캡 나사 ⑦ DIN 7984 M2.5 × 8 × 3 + 황동 인서트 M2.5 × 3(r 20.5, 90° + 120°k). 위치는 `fusion/legs_v5.py`의 값.
- 링크 속에서 일어나는 단계(받침 링을 Ø44 구멍에 넣기, 무릎 판 쪽 ① 조이기, 정강이 준비)는 링크를 반투명하게 그렸다.
  깊은 구멍으로 넣는 출력 나사 ②는 구멍 축 쪽에서 들여다보는 시점이다.
- 번호는 `manufacturing/explain/*_section.png`(실제 단면도)와 같다: ① 고정자 나사, ② 출력 나사, ③ 평행핀, ④ moteus 나사,
  ⑤ 컵 나사, ⑥ 플랜지 볼트, ⑦ 캡 나사. 바퀴의 ④는 v2처럼 림 나사다.

## 다시 만들기

Fusion이 켜져 있을 때 `scripts/`에서(f3d를 저장하지 않는 문서로 한 번 가져와 다음 작업에도 쓰고, 작업마다 저장하지 않는 새 문서를 연다),
`<job>` = `hip` · `knee` · `wheel`:

```
python fusion_rpc.py f5_build.py 900 <job>      # 작업 문서 + 부품 복사 + 모델에 없는 체결 부품
python fusion_rpc.py f5_stills.py 1500 <job>    # 스틸 -> %TEMP%\wbv5_assembly\<job>\raw
python -X utf8 annotate.py %TEMP%\wbv5_assembly\<job>\raw ..\<job>
python fusion_rpc.py f5_video.py 3000 <job>     # 영상 프레임 -> %TEMP%\wbv5_assembly\<job>\frames
python -X utf8 compose_video.py %TEMP%\wbv5_assembly\<job> ..\<job> ..\<job>\<job>_assembly.mp4
```

`axlib5.py` = 공통 엔진(v2 `axlib.py`를 v5용으로 고침: f3d 가져오기, 몸체 이름·위치로 고르기, 모델 체결 부품을 하나씩 축과 함께 복사,
반투명 단계, 임의 위치로 옮기기, 단계 시작 위치 `pre`). `job5_<job>.py` = 부품 목록, 분해 위치(`home`), 단계, 카메라, 단면, 라벨 문구.
`annotate.py`·`compose_video.py`는 v2 것과 같다(긴 제목은 글자를 줄여 단계 상자와 겹치지 않게 함). `compose_video.py`의
ffmpeg 경로는 `FFMPEG`. 모듈 이름이 `axlib5`·`job5_*`라서 같은 Fusion 세션에서 v2 스크립트(`axlib`·`job_*`)와 섞이지 않는다.
렌더하는 동안 마우스 커서를 Fusion 화면 밖에 둔다(커서 밑 면이 하이라이트되어 그림에 찍힌다).
