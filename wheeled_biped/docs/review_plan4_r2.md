## 2. 모델 검토

### 2.1 유도 재확인 (`plant_serial.py:62-101, 239-259`)

- 바퀴 모터는 종아리(L0 고정이면 가상 다리와 함께 θ로 회전)와 바퀴(절대각 x/R) 사이에 있으므로 관절 좌표는 ω = ẋ/R − θ̇다. 가상일 δW = T(δx/R − δθ) ⇒ Q_x = T/R, Q_θ = −T. 감쇠 토크 −c_w ω도 같은 자리에 걸려 Q_x = −c_w ω/R, Q_θ = +c_w ω. MuJoCo `dof_armature`는 관절 좌표의 질량 행렬 대각에 더해지므로 운동 에너지 항은 ½J_w ω² = ½J_w(ẋ/R − θ̇)²(코드 80행, 84~85행과 같음).
- 엉덩이 모터는 몸체–허벅지 사이 q̇_hip = θ̇ + φ̇: ½J_h(θ̇ + φ̇)², Q_θ·Q_φ에 +Tp와 −c_h(θ̇ + φ̇).
- 감쇠 행렬: Q_damp = −D q̇에서 D = [[c_w/R², −c_w/R, 0], [−c_w/R, c_w + c_h, c_h], [0, c_h, c_h]](247행과 같음). E = [[1/R, 0], [−1, 1], [0, 1]](248행).
- 나머지(바퀴 절대 회전 ½I_w(ẋ/R)², 다리 ½m_l|ṗ_l|² + ½I_lθ̇², 몸체 ½m_b|ṗ_b|² + ½I_bφ̇², V = g(m_l z_l + m_b z_b))는 1라운드에서 확인한 그대로다.

### 2.2 MuJoCo 투영 독립 검사 (`plant_projection_check.py`)

평면 좌표 (x, θ, φ) → MuJoCo `qpos` 사상을 직접 만들고(IK, 무릎 고정, 바퀴 관절 = x/R − 종아리 절대각, 축이 (x, R)에 오게 base 배치) 그 접공간 사상 P를 `mj_differentiatePos` 중앙차분으로 구해 verify 스크립트의 손으로 쓴 P와 독립적으로 비교했다(L0 = 0.25·0.28·0.31·0.33).
