## 7. 권고(우선순위)

1. **M1(r2)**: `obs_hold_s` × `decel_factor`(× `ref_omega_down`) 격자를 전체 매트릭스에서 다시 쓸고(예: 1.2 / 1.0 s는 두 주기 19번 45/45), 공식 재실행 뒤 "물리적 한계" 서술과 사용자 결정 항목(9절, 비교보고서 11절, 응답 문서)을 고친다. 실기 여유(m7)를 위해 명령 지연을 모델에 넣고 같은 격자를 다시 본다.
2. **M2(r2)**: 20번의 비교 단위(항목의 가장 빠듯한 지표 대 지표별)를 사용자 결정 항목으로 올리고, 지표별 악화(정지 거리 +27~29 %, 실행 단위 피치 +21 %·바퀴 피크 +19 %)를 20번 행에 함께 표시한다. 지표별 판정이면 19번(2° 피치)과의 상충을 함께 보고한다.
3. **M3(r2)**: 서술 수치를 공식 JSON에서 다시 뽑고, `results/plan4_mpc/`의 1라운드 산출물을 정리하고, 결과 머리에 코드 해시를 남긴다.
4. minor: m1(OSQP `self.period` 한 줄 + 테스트), m7(지연 모델), m2·m3(제동 구간 모델링·넘김 방향), m6(성형 전환 시 기준 연속), m4(동결 히스테리시스), m8(독스트링), m9(패킷 속도 검사).
