## 1. 기구학 (`serial_leg.py`)

엉덩이 좌표계: x 앞, z 위, 회전은 +y 축. 길이 L인 링크가 아래를 향한 상태에서 절대각 t만큼 돌아간 방향을 u(t) = (−sin t, −cos t)로 둔다(양의 각 = 링크 끝이 뒤로 가는 회전, 설계보고서 5절 링크와 같은 규약).

- 허벅지 절대각 t₁ = q_hip, 종아리 절대각 t₂ = q_hip + q_knee (q = 0이면 다리가 수직으로 펴짐)
- 바퀴축 위치 p = L₁ u(t₁) + L₂ u(t₂)
- 가상 다리(엉덩이→바퀴축): 길이 L0 = |p|, 각도 θ_v = atan2(−p_x, −p_z) (양 = 엉덩이가 바퀴보다 앞)
- 야코비안 ∂p/∂q = [L₁u′(t₁)+L₂u′(t₂), L₂u′(t₂)], u′(t) = (−cos t, sin t)
- 역기구학: 엉덩이–무릎–바퀴축 삼각형에서 cos a = (L₁²+L0²−L₂²)/(2L₁L0), t₁ = θ_v + s·a (s = knee_sign; Plan 4는 s = −1, 무릎 앞), t₂는 p − L₁u(t₁)에서
- VMC: 가상 다리 힘 F(양 = 신장)와 엉덩이 토크 Tp(다리에 +y로 작용, 몸체 반작용 −Tp)를 τ = Jᵀ[F u(θ_v) + (Tp/L0) u′(θ_v)]로 관절 토크에 사상. L0 고정 상태에서 Jᵀ의 엉덩이 성분은 정확히 Tp가 된다(∂p/∂q_hip = L0 u′).
- 종아리(바퀴 캐리어) 각속도 = q̇_hip + q̇_knee (5절 링크에서는 크랭크 각속도). MCU의 바퀴 접지 속도 추정 v = R(q̇_wheel + 종아리 월드 각속도)에 쓴다.
- 특이점: 무릎 완전 신장(q_knee = 0, L0 = 0.343 m)에서 야코비안이 랭크를 잃어 다리 길이를 제어할 수 없고 무릎 굽힘 방향이 정해지지 않는다. 역기구학은 L0를 L0_max − 1 mm로 제한하고, 서는 자세는 무릎을 굽힌 0.31 m로 둔다.
- 관절 한계(URDF): 엉덩이 ±1.26 rad, 무릎 ±2.51 rad. 서는 자세 q = (−0.513, +0.885) rad, 가장 낮은 L0 = 0.22 m에서 (−1.08, +1.75) rad으로 한계 안.

### upkie 관절 부호

upkie의 관절은 좌우가 거울상이다. 왼쪽 엉덩이·무릎은 +각이 다리를 앞으로 흔들고(−y 회전), 오른쳍은 뒤로 흔든다. 왼쪽 바퀴의 +속도는 전진(+y 회전), 오른쪽은 후진이다. MCU는 위의 u 규약(양 = +y 회전)만 보도록, 플랜 조립 코드가 관측값과 토크 명령에 부호 어댑터 `UPKIE_JOINT_SIGNS = {left_hip −1, left_knee −1, left_wheel +1, right_hip +1, right_knee +1, right_wheel −1}`를 곱한다(`plan4_upkie_lqi6.py`). MuJoCo 모델에서 관절축을 월드로 변환해 확인했다(왼쪽 엉덩이 +0.2 rad → 바퀴축 +6.8 cm 전진 = 0.343·sin 0.2).

## 3. 라그랑지안 유도 (`plant_serial.py`)

일반화 좌표 q = (x, θ, φ): x 바퀴 위치, θ 가상 다리각(양 = 엉덩이가 앞, +y 회전), φ 몸체 피치(양 = 몸체가 뒤로 기움, −y 회전; IMU 피치의 −). 다리 길이 L0는 다리 PD가 유지하는 준정적 파라미터다. 엉덩이 관절각(u 규약)은 q_hip = θ + φ.

위치(x, z):
- 바퀴 (x, R), 각도 x/R (미끄럼 없음)
- 다리 무게중심 p_l = (x + d cos θ + c sin θ, R − d sin θ + c cos θ)
- 엉덩이 p_h = (x + L0 sin θ, R + L0 cos θ)
- 몸체 무게중심 p_b = p_h + (b_x cos φ − b_z sin φ, b_x sin φ + b_z cos φ)

운동·위치 에너지:

T = ½(m_w + I_w/R²)ẋ² + ½m_l|ṗ_l|² + ½I_l θ̇² + ½m_b|ṗ_b|² + ½I_b φ̇² + ½J_h(θ̇ + φ̇)² + ½J_w(ẋ/R − θ̇)²,  V = g(m_l z_l + m_b z_b)

일반화 힘(T 바퀴 총토크, 양 = 전진 구동; Tp 엉덩이 총토크, 다리에 +y로 작용):

Q_x = T/R − c_w ω/R,  Q_θ = −T + Tp − c_h(θ̇ + φ̇) + c_w ω,  Q_φ = Tp − c_h(θ̇ + φ̇),  ω = ẋ/R − θ̇ (바퀴 관절 속도)

직렬 구조가 들어가는 곳: (i) L0에 따라 바뀌는 다리 집중 파라미터, (ii) 엉덩이 토크가 몸체–허벅지 관절 q_hip = θ + φ에 걸리므로 θ와 φ 모두 +Tp를 받고, 바퀴 반작용 −T는 다리만 받는다(L0가 고정이면 종아리는 가상 다리와 함께 회전하므로 바퀴 토크의 반작용은 다리에 대한 순수 토크), (iii) 엉덩이 로터 아마추어가 q̇_hip에, 바퀴 로터 아마추어 J_w와 바퀴 점성 감쇠 c_w가 바퀴 관절 속도 ω = ẋ/R − θ̇에 붙는다(바퀴 모터는 종아리와 바퀴 사이에 있으므로; 무릎을 잠근 대조 모델에서 종아리는 가상 다리와 함께 돈다). 5절 평행사변형 플랜트(`plant6.py`)는 몸체 피치와 다리각이 기구적으로 분리되어 있다는 가정으로 세운 식이라 재사용하지 않았다.

오일러–라그랑주 식 d/dt(∂L/∂q̇) − ∂L/∂q = Q를 sympy로 세우고 q̈에 대해 선형인 꼴 M_acc q̈ = rhs로 정리한다(비선형 시뮬레이션용). 선형화는 평형점에서 해석적으로 한다.

### 평형

몸체 수평(φ = 0)에서 ∂V/∂θ = Q_θ = Tp, ∂V/∂φ = Q_φ = Tp 이므로 ∂V/∂θ = ∂V/∂φ, 즉

m_l(d cos θ + c sin θ) + m_b(L0 sin θ + b_x) = 0  (전체 무게중심이 바퀴축 위)

를 θ_eq(L0)에 대해 풀고, 정적 엉덩이 토크는 Tp_eq = m_b g b_x = −0.314 Nm이다. θ_eq 표(L0 격자): 0.25 m −8.00°, 0.28 m −5.79°, 0.31 m −3.48°, 0.33 m −1.54°. MuJoCo 전체 모델에서 무게중심을 이분법으로 맞춘 값(−3.47° at 0.31)과 0.01° 안에서 같다. 제어기는 φ_ref = 0, θ_ref = θ_eq(L0 측정값)을 쓰고 Tp_eq를 상수 피드포워드로 더한다(상수는 선형화를 바꾸지 않는다).

### 선형화

평형점 (q_eq, q̇ = 0)에서 M(q_eq) δq̈ = −H_V δq − D δq̇ + E δu. H_V는 V의 헤시안(중력 강성), D = [[c_w/R², −c_w/R, 0], [−c_w/R, c_w + c_h, c_h], [0, c_h, c_h]] 감쇠(바퀴 감쇠는 관절 속도 ω에, 엉덩이 감쇠는 θ̇ + φ̇에), E = [[1/R, 0], [−1, 1], [0, 1]]. 상태 X = [θ, θ̇, x, ẋ, φ, φ̇], 입력 U = [T, Tp]로 재배열해 A(6×6), B(6×2)를 얻는다. L0 = 0.31에서 개루프 극: +6.13, +9.77(불안정), −7.53, −10.76, 0, −0.11 rad/s. 단위 테스트가 비선형 `deriv`의 수치 미분과 A·B를 1e−6 수준에서 맞춘다. 느린 극은 전체를 한 역진자로 본 √(g l_com) ≈ 6.4와 맞고, 빠른 극은 몸체가 엉덩이 위에서 넘어지는 모드다.

평형각이 작아 대칭 플랜트에 가깝고 관절 한계에서 멀어서 무릎 앞을 택했다. 서는 길이 0.31 m는 완전 신장(0.343, 특이점)에서 3.3 cm 아래, 4 cm 웅크림(0.27 m)과 롤 보상(±2.5 cm)을 할 수 있는 위치다. 정적 무릎 토크는 1.38 Nm(qdd100 16 Nm의 9 %).

### 타이어 반경과 발목 하우징 간섭

upkie_description의 타이어 충돌 실린더 반경은 0.05 m이고, 발목 모터 하우징(ankle_stator 충돌 박스 92×68×56 mm)의 최저점은 선 자세에서 바닥 위 3.5~10 mm다. 반경 0.05 m로는 L0 = 0.31에서 앞으로 7°, L0 = 0.27(4 cm 웅크림)에서는 0°에서 바닥에 닿는다(`scratch pitch_limit`). 실제 upkie BOM은 112 mm RC 타이어(R = 0.056)이고 upkie 스파인 설정은 0.06 m를 쓴다. Plan 4는 BOM 값 0.056 m로 두 번째 모델 디렉터리 `models/upkie_plan4`를 만들어 쓴다(`python -m wbr.models.build_upkie --out models/upkie_plan4 --tire-radius 0.056`). Plan 1~3 결과는 기존 모델(0.05)로 낸 것이므로 그대로 둔다. **실기 시 주의**: 100 mm 타이어를 쓰면 발목 하우징이 바닥에 닿아 기울기·웅크림 여유가 거의 없다.

## 5. MuJoCo 대조 (`verify_plan4_plant.py`, `results/plan4_model/linearization.json`)

조건: MuJoCo 모델(`models/upkie_plan4`, 타원체 타이어)에서 무릎 관절을 아마추어 1000 kg m²로 잠가 가상 다리를 강체로 만들고(축약 모델의 가정), 관절 건마찰은 0으로, noslip 후처리는 끈 상태(역동역학과 순동역학의 일관성), **대조용으로 바닥·타이어 접촉 임피던스를 강성(solimp 0.99/0.999)으로** 둔다(기본값 `--soft-contact`로 모델의 0.9/0.95를 유지할 수 있다). 모델의 연한 접촉은 정적 역동역학에 −1.2 N의 base 잔차를 남겨(자세가 정확한 평형이 아님) 정적 엉덩이 토크를 7 % 틀리게 하고 개루프 φ 오차를 키운다 — 플랜트가 아니라 대조 절차의 문제였다(검토 1라운드 m10). 정적 토크는 평형 자세에서 접촉이 안정된 뒤 `mj_inverse`(q̈ = 0)로 구했다. 네 가지를 비교했다.

1. **정적 토크**: 엉덩이 총토크 MuJoCo −0.315~−0.319 Nm vs 모델 −0.314 Nm(base 잔차 0.16 N; 연한 접촉으로는 −0.272~−0.303 Nm, 잔차 1.18 N). 무릎 정적 토크 1.36 Nm(0.31).
2. **B 행렬**(초기 가속도): 바퀴 토크 0.2 Nm 스텝과 엉덩이 토크 1 Nm 스텝에 대한 (ẍ, θ̈, φ̈)를 `mj_forward`와 M⁻¹E u로 비교. 벡터 노름 오차와 **성분별** 상대 오차를 함께 적는다(노름은 큰 φ̈ 성분이 지배해 ẍ 성분 오차를 가린다, m10).
3. **A 행렬**: `mujoco.mjd_transitionFD`(중앙차분 1e-6)로 얻은 이산 A_d를 log(A_d)/Δt로 연속화하고, 고유벡터가 좌우 대칭 평면 부분공간(x, θ, φ 사상 P)에 50 % 이상 놓이는 고유값만 골라 모델의 고유값과 비교.
4. **개루프 응답**: 평형 자세를 바퀴축 중심으로 3° 통째로 기울이고(θ += 3°, φ −= 3°) 정적 토크를 유지한 채 0.3 s 동안 MuJoCo와 모델(RK4)을 비교. 0.3 s 전체 rms와, 선형 모델이 유효한 |θ − θ_eq| < 6° 구간(약 0.13 s)의 rms를 따로 적는다.

### 대조 과정에서 바로잡은 것

- 관절 건마찰을 켠 채 미분하면 MuJoCo의 엉덩이가 잠긴 것처럼 보여 불안정 극이 하나만 나왔다(4.7 rad/s). 선형 모델에는 건마찰이 없으므로 대조 때 끈다. 실기에서는 이 0.1 Nm 데드밴드가 작은 피치 오프셋·느린 한계 사이클의 원인이 될 수 있다(6절).
- 기울인 자세에서 접촉 안정화를 다시 하면 강체 로봇이 0.1 s 동안 넘어지므로, 평형에서 한 번만 안정화하고 그 높이 오프셋을 기울인 자세에 더한다. 키프레임 리셋이 ctrl을 지우므로 정적 토크를 다시 넣는다.
- 타이어 반경 0.05 모델에서는 3.5° 이상 기울면 발목 하우징이 바닥에 닿아(접촉 4→8개) 응답이 모델과 갈라졌다. 이것이 4절의 타이어 반경 교정으로 이어졌다.
- (검토 1라운드 m9) 바퀴 로터 아마추어(2×0.0003 kg m², I_w의 63 %)를 I_w에 합쳐 절대 회전 ẋ/R에 붙였었다. MuJoCo는 아마추어를 관절 좌표(바퀴 − 종아리)에 붙이므로 ½J_w(ẋ/R − θ̇)²로 따로 두고 바퀴 감쇠도 관절 속도로 바꿨다 → 빠른 극 오차 2.9 % → 0.02 %, B 성분 오차 7.2 % → 0.3 %. 게인 표는 자동으로 다시 만들어진다(`plan4_params.json`에 `J_w`).
- (m10) 대조 때 접촉 임피던스를 강성으로 두고(base 잔차 1.18 → 0.16 N), B 오차를 성분별로, 응답 비교를 선형 구간으로도 보고한다.
- 타이어 충돌체는 타원체(접점 하나)이고 검토 1라운드 뒤 `condim 4`(비틀림 마찰 0.005)로 바꿨다(`python -m wbr.models.build_upkie --out models/upkie_plan4 --tire-radius 0.056 --tire-shape ellipsoid --tire-condim 4`). 대조 결과에는 영향이 없고(평면 운동), 9번 요 항목의 유지 토크에 영향을 준다(`docs/plan4_lqi6.md`).

## 6. 모델의 한계와 제어기에 미치는 영향

- **다리 길이 PD**: 모델은 L0를 고정으로 본다. 실제로는 kp_leg = 800 N/m, kd_leg = 40 N s/m의 PD가 유지하므로 다리 길이 모드(≈√(800/2.5) ≈ 18 rad/s, 3 Hz)가 균형 모드(6~10 rad/s)와 완전히 분리되지는 않는다. 벤치마크에서 영향은 L0 흔들림 ±1 mm 수준.
- **다리 힘 피드포워드**: 질량 없는 다리를 가정한 VMC에 로봇 전체 무게를 넣으면(5절 링크 MCU 기본식) 다리가 7 mm 과신장된다. 몸체 무게 + 다리 무게의 c/L0(≈42 %) 비율을 쓰면(18.2 N/다리) 1 mm 안으로 맞는다.
- **건마찰**: 모델에 없다. 노이즈가 없을 때 피치 0.5° 오프셋이 남고, 노이즈가 있으면 디더링으로 사라지지만 x가 수 cm 느리게 왕복한다. 적분 가중치로 보상한다(`docs/plan4_lqi6.md`).
- **접촉**: 미끄럼 없음 가정. 마찰 0.5에서의 거동은 합격 판정 매트릭스에서 확인한다. 모델의 접촉은 연하다(solimp 0.9/0.95: 정적 자세가 1.2 N만큼 평형에서 벗어나고 타이어가 수 mm 눌림). 제어기는 이것을 모르며 합격 판정 시뮬은 모델 기본값으로 돈다(강성 접촉은 대조 전용).
