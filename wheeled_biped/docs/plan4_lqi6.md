- **MCU 센서 가드**: 비유한 표본은 추정값 유지 → 5주기 넘으면 FAULT, 시간 스탬프 정지 50 ms → FAULT, 비유한 토크 명령 → 0 + FAULT, 롤 34° FAULT. LQI6는 비유한 입력에서 직전 출력 유지(1.6절).
- **IMU 관례 어댑터**: MCU가 upkie 스파인의 `BaseOrientation` 변환(ARS 좌표 + IMU 180° 장착)을 갖고, 시뮬레이션은 IMU 표본을 스파인이 보고하는 방식으로 내보내 어댑터가 모든 판정에서 실행된다(1.1절).
- **마찰 보상 피치 속도 게이트** 1/(1 + (φ̇/0.1 rad/s)²): 보상은 정지 보조로만 작동하고 균형 루프 대역에 이득을 더하지 않는다(1.4절, 2절 12).
- **타이어 접촉**: 타원체 + `condim 4`(비틀림 마찰 0.005). 9번 요 항목의 유지 토크가 조금 늘었다(바퀴 rms 0.07 → 0.11 Nm, 기준 0.2).
- **판정 정의**(합격기준 6.2): 이동·정지 거리 = 최대 이탈, 정착 유지 1 s, 정지형 항목 생존 검사, 모터별 rms, 생존 항목 시드 5개, 11번 3 s 순항 뒤 끊김, 15번 강건 여유 기록, 24번 기록 항목(주행 중 밀기), 캐시 해시 범위.
- **시뮬 지연선**: 준비 구간의 반복 표본을 과거 시각으로 스탬프한다(`ObservationDelay(dt=…)`). 정지 감시가 시작 시 추정을 붙잡으면 첫 표본의 1스텝 미분 속도 잡음이 10 ms 동안 유지되어 1 kHz 10°·15° 복귀가 깨졌다(2절 13).
- 2단계용으로 LQI6 플레인 모드(호스트 성형 기준)에 "가속 중 적분기 전부 동결"이 들어갔다. 1단계(램프 호스트, 자체 성형)에는 영향이 없다.

## 1. 제어기 구조

### 1.1 상태와 입력

MCU(`DiabloMcu`, 1 kHz 또는 200 Hz)가 IMU와 6개 관절을 읽어 추정하고 `LQI6Law`가 총 바퀴 토크 T와 총 엉덩이 토크 Tp를 낸다(u = −K x). 상태(플랜트 규약은 `docs/plan4_model.md` 3절):

| 상태 | 정의 | 측정 |
|---|---|---|
| θ | 가상 다리 월드 각 − θ_eq(L0) (θ_eq(0.31) = −3.48°) | 엔코더(몸체 기준 다리각) + IMU 피치 |
| θ̇ | 다리각 속도 | 5 ms 위치 차분 속도 + 자이로 |
| v − v_ref | 바퀴 접지 속도 − 성형된 기준 | 바퀴·종아리 5 ms 차분 속도 + 자이로 |
| φ | 몸체 피치(−IMU 피치, 뒤로 기울면 +) | IMU |
| φ̇ | 몸체 피치 속도 | 자이로 |
| z1 | ∫(v − v_ref) dt (= 위치 오차) | |
| z2 | ∫e_att dt, e_att = θ + φ + (Tp − T)/(g·M(L0)) — 정적 몸체 기울기(IMU 바이어스가 θ + φ에서 상쇄) | 엔코더 + 명령 토크 |
| z3 | ∫z1 dt — 위치 오차의 적분(일정 외란 토크를 위치 오프셋 없이 떠안음) | |

- **IMU 입력**: 실기 upkie의 pi3hat은 IMU 자세를 ARS 좌표(x 앞, y 오른쪽, z 아래)로, 각속도를 IMU 좌표로 보고하고 IMU는 토르소에 y축 180° 돌려 붙어 있다. MCU는 upkie 스파인과 같은 변환 R_base→world = R_ARS→world · R_IMU→ARS · R_base→IMU(`McuParams.imu_rotation_base_to_imu` = diag(−1, 1, −1), `imu_rotation_ars_to_world` = diag(1, −1, −1))으로 base 자세·각속도를 복원한다. 시뮬 플랜은 base 사이트의 센서값을 그 관례로 재표현해 넘긴다(`Plan4Config.real_imu_convention`, 기본 켬) — 변환 왕복이 세계 좌표 추정과 1e−9 안에서 같음을 단위 테스트로 확인했다. 실기에서 장착 회전이 다르면 URDF에서 다시 읽어 넘긴다.
- 입력 u = [T, Tp]: T는 두 바퀴 합(양 = 전진 구동), Tp는 두 엉덩이 합(다리에 +y로 작용). MCU가 T·Tp에 마찰 보상, 요 토크(차동), anti-split, 다리 길이 PD + 무게 피드포워드를 더해 직렬 다리 VMC(τ = Jᵀ[F u + (Tp/L0) u′])로 관절 토크를 만든다. upkie 관절은 좌우 거울상이라 부호 어댑터(`UPKIE_JOINT_SIGNS`)를 거친다. MCU에 넘기는 관측 dict에는 시뮬 참값(`sim` 키)이 없다.

### 1.2 게인 설계

- 플랜트: `plant_serial.py`의 3체 직렬 다리 모델을 L0 = 0.22~0.34 m(5 mm 간격)에서 선형화, 제어 주기 Ts(1 ms 또는 5 ms)로 ZOH 이산화, 적분 상태 z1·z2·z3을 붙여 이산 LQR(DARE)을 격자마다 풀어 표로 두고 실행 중에는 측정 L0로 보간한다(MCU 안에서 리카티를 풀지 않음). 플랜트 파라미터는 `models/upkie_plan4/plan4_params.json`(`python -m wbr.models.upkie_params`로 재생성, 실기 측정값으로 교체 가능).
- Bryson 가중치(Q = diag(1/q²), R = diag(1/(r·τ_max)²)): q_θ 0.3 rad, q_θ̇ 3 rad/s, q_v 0.5 m/s, q_φ 0.15 rad, q_φ̇ 3 rad/s, q_int 0.2 m, q_att 0.2 rad·s, q_pos 0.5 m·s, r_wheel 0.2 × 1.7 Nm(바퀴가 병목), r_hip 0.3 × 16 Nm.
- L0 = 0.31 게인(8상태 [θ, θ̇, v−v_ref, φ, φ̇, z1, z2, z3]):
  - 1 kHz: K_T = [−7.62, −1.13, −1.98, 1.59, 0.23, −2.26, 0.47, −0.64], K_Tp = [20.36, 2.72, 5.32, 29.56, 1.43, 8.42, 22.11, 2.56]
  - 200 Hz: K_T = [−7.37, −1.09, −1.88, 1.54, 0.23, −2.14, 0.46, −0.61], K_Tp = [17.09, 2.25, 4.38, 25.35, 1.28, 6.97, 18.77, 2.12]
- 위치 강성(정상상태 외란 토크 → 위치 오프셋)은 z1 게인 2.26 Nm/m가 정하고, z3이 그 오프셋을 시간이 지나면 0으로 되돌린다. 바퀴 채널의 θ 게인(−7.6 Nm/rad)과 엉덩이 채널의 φ 게인(30 Nm/rad)이 각각 다리와 몸체의 역진자를 세운다.

### 1.3 정적 자세 적분 z2

정지 상태에서 Σm·x(바퀴축 기준) = T/g 이고 엉덩이 정적 토크 = 몸체(+탑재물)의 엉덩이 기준 중력 모멘트다. θ, φ에 대해 선형화하면 φ_실제 ≈ Δθ_body + (ΔTp − T)/(g M), M = ∂Σm x/∂θ ≈ 1.15 kg·m(L0 = 0.31)이고 Δθ_body = θ + φ는 엔코더만으로 정해진다(IMU 바이어스 상쇄). 이것을 적분 상태로 LQR에 넣어 정상상태에서 실제 몸체가 수평이 되게 한다. 유효한 것은 준정적 상태뿐이라 기준 가속도(0.1 s 저역통과)가 0.1 m/s²를 넘는 동안은 적분을 멈춘다. 남는 오차: 탑재물 질량 자체의 모멘트 차(17번에서 +0.4°), 질량 ±15 %(∓0.25°).

### 1.4 피드포워드와 보상

- Tp 피드포워드 Tp_eq = m_b g b_x = −0.314 Nm(몸체 무게중심이 엉덩이 1.15 cm 뒤). 상수는 선형화를 바꾸지 않는다.
- 다리 힘 피드포워드 F_ff = ½(m_b + (c/L0) m_l) g = 18.2 N/다리(다리 무게의 42 %만 가상 다리로 전달; 전체 무게를 쓰면 7 mm 과신장). 다리 길이 PD 800 N/m, 40 N s/m.
- **마찰 보상**(모델 건마찰 엉덩이 0.1·바퀴 0.02 Nm의 80 %): 엉덩이 +2·0.08·tanh(dev/0.02), 바퀴 +2·0.016·tanh(T/0.02), dev = (Tp − Tp_ff) − LPF₁ₛ(Tp − Tp_ff). 두 항에 **피치 속도 게이트** 1/(1 + (φ̇/0.1)²)를 곱한다(검토 1라운드 M1): 보상은 정지 중 건마찰 헌팅(피치·x 왕복)을 없애기 위한 것이고, 릴레이처럼 작동하는 tanh 항이 큰 진폭 진동에서 균형 루프의 고주파 이득을 키우던 것을 막는다. 정지 품질·드리프트는 게이트 전과 같고(피치 MA 0.28°, 드리프트 2 cm) 1 kHz 12 ms 지연에서 2.1° 한계 사이클이 사라진다(2절 12). 실기에서는 0에서 시작해 측정한 마찰로 올린다(HANDOFF 2.1).
- anti-split PD kp 60 Nm/rad·kd 3 Nm s/rad(upkie의 가벼운 다리는 Plan 2의 15/0.8로는 묶이지 않아 차동 토크가 요 대신 다리를 벌렸다). 요 PI kp 0.4·ki 0.8, 적분 한계 1.0 rad. 롤: 다리 길이 차 PI.
- 속도 기준 성형(1단계·폴백): 램프 2 m/s² → 1차 전치필터 τ 0.3 s(가속 시에만) → 기준이 움직이는 동안 z1·z2·z3 동결, 전치필터가 램프의 0.05 m/s 안에 들면 해제. 0.5 m/s 스텝 오버슈트 6~10 %, 90 % 도달 1.2~1.25 s. 가속 피드포워드는 비최소위상 특성 때문에 악화된다(47 %).

### 1.5 200 Hz 지원

같은 설계를 Ts = 5 ms로 다시 이산화한다(게인 표, 지연 10 ms = 2 스텝, 속도 창 5 ms = 1 스텝). 200 Hz 결과는 1 kHz와 거의 같고 지연 허용(15번)은 25 ms로 기준을 만족한다(1 kHz 20 ms).

### 1.6 센서 가드와 FAULT (검토 1라운드 M2·m12)

| 조건 | 동작 |
|---|---|
| IMU 쿼터니언 비유한 또는 노름 ≠ 1 ± 0.1, 자이로·관절 위치·속도 비유한 | 추정값 유지(위치 차분 창은 시간축 유지), `max_bad_samples`(5) 연속 초과 → FAULT + 이벤트 |
| 관측 시간 스탬프가 전진하지 않음(드라이버 데이터 정지) | 추정값 유지, 50 ms(`stale_fault_s`) 초과 → FAULT |
| LQI6 입력 비유한 | 직전 출력 유지(적분기 갱신 없음) |
| 관절 토크 명령 비유한 | 0 전송 + FAULT + 이벤트(전에는 조용히 0) |
| \|피치\| > 34°, \|롤\| > 34° | FAULT(전 관절 무토크) |
| 호스트 링크 500 ms 타임아웃 | 단절 프로그램(속도·요 0, 자세 유지, `host_shaped = False` → 자체 성형) |

단위 테스트(`tests/test_plan4_safety.py`): 자이로·엔코더 NaN 1표본(유지, 전복 없음)·8표본(FAULT), 정지 시간 스탬프(40 ms 유지, 60 ms FAULT), 시간축 유지, 지연선 준비 구간이 가드를 건드리지 않음, 롤 FAULT, IMU 어댑터 왕복. 실기 진입점은 `reset(armed=False)` 뒤 직립 확인 후 `arm()`(시뮬 하네스는 armed=True); 들림 감지·관절 한계 FAULT는 아직 없다(HANDOFF 2.1).

### 1.7 호스트 성형 플래그와 플레인 모드

호스트가 `MotionCtrl.host_shaped = True`를 보내면(2단계 MPC) MCU가 LQI6를 플레인 추종(램프 4 m/s², 필터 없음)으로 바꾸고, **기준이 가속하는 동안(저역통과 0.1 s 가속도 > 0.1 m/s²) 적분기 z1·z2·z3 전부를 동결**한다(`freeze_int_on_accel_plain`). 링크 타임아웃이나 호스트의 QP 실패(폴백) 때는 플래그가 거짓이 되어 1단계 성형으로 돌아간다. MCU는 자체 기준 `v_ref`(성형된 v_filt)를 텔레메트리에 싣는다(호스트의 무충격 재동기용).

## 2. 튠 과정에서 배운 것

1. **건마찰 헌팅**: 엉덩이·무릎 0.1 Nm 건마찰은 선형 모델에 없고, 노이즈를 모두 꺼도 피치 왕복(rms 0.16°)과 x 왕복 ±3 cm를 만든다(마찰을 끄면 사라짐). 토크 노이즈가 디더 역할을 하고 있었기 때문에 속도 필터만 넣으면 헌팅이 커진다 → 운동 방향 기준 마찰 보상과 함께 써야 한다. 엉덩이 보상을 끄면 정지 피치 MA가 0.28 → 0.46~0.50°로 나빠진다.
2. **바퀴 떨림의 원인은 엔코더 미분 노이즈**: 14-bit 엔코더를 1 kHz 한 스텝으로 미분한 ±0.38 rad/s 노이즈가 θ̇ 게인을 거쳐 바퀴 토크 노이즈(rms 0.096 Nm)와 베이스 고주파 속도 6.1 mm/s가 됐다. 5 ms 위치 차분(지연 2.5 ms)으로 0.037 Nm·1.0 mm/s. 바퀴 보상(0.016 Nm)을 끄면 토크 rms가 0.029로 더 줄지만 피치 MA 0.27 → 0.44°, 드리프트 1.8 → 2.7 cm로 나빠져 유지한다.
3. **바퀴 토크 1.7 Nm 병목**: 10° 기울기 복귀 바퀴 피크가 1.27~1.32 Nm(한계 1.36)로 가장 먼저 걸린다. 위치·속도 루프를 세게 하는 모든 변경이 이 한계에 먼저 닿는다.
4. **저마찰 15° 복귀는 바퀴 슬립과의 경쟁**: m×0.85·μ0.5에서 바퀴가 0.1 s 이상 포화하면 미끄러져 넘어진다. q_pos 0.5가 포화를 0.007 s로 줄여 통과시켰고, 더 센 적분(q_int 0.1~0.15)은 다시 넘어지거나 1 kHz에서 불안정했다.
5. **요가 다리 벌어짐으로 샌다**: anti-split 60 Nm/rad. 그리고 **타이어 스크럽**: 원기둥 충돌체의 림 양끝 두 접점이 제자리 회전 때 서로 미끄러져 바퀴당 0.12~0.22 Nm를 계속 먹는다 → 타원체 충돌체. condim 4(비틀림 마찰)에서도 9번은 바퀴 rms 0.11 Nm로 통과한다(기준 0.2).
6. **경사가 적용되지 않던 버그**: `geom_quat`만 바꾸면 컴파일러의 `geom_sameframe` 표시 때문에 무시된다.
7. **질량 스케일과 밀기 힘**: `body_mass`만 바꾸면 총질량 파생값이 갱신되지 않는다(`mj_setConst`).
8. **일정 외란은 위치 이탈로 나타난다**: z1(속도 적분 = 위치)이 외란 토크를 떠안아 이동 = 외란 토크 / K_z1. 경사·페이로드·IMU 바이어스가 모두 같은 식이다. q_int 0.2 + q_pos 0.5로 경사 정지(12)는 10 cm 기준을 통과하지만 16·17의 5 cm 기준은 9~11 cm로 미달이다(4절).
9. **z_att의 유효 범위**: 가속 중에는 적분하면 안 된다(2단계 19번). 반대로 속도 오차가 클 때 멈추면 밀기 복귀가 느려진다(5번).
10. **지연 허용은 엉덩이 루프 대역폭이 정한다**: r_hip 0.15로 낮추면 30 ms지만 밀기 피치가 +3°. 10 ms 예측기를 켜면 30 ms지만 밀기 피치가 두 배다.
11. **극한 강건성과의 교환**: 합격 판정용 튠으로 표준 벤치마크의 최대 기울기는 30 → 25°, 최대 밀기는 2.5 → 1.5 W(1 kHz)·1.75 W(200 Hz)로 줄었다. 기준(20° 생존, 1.0 W 생존)은 유지된다.
12. **지연 여유는 15번 시험(3° 기울기·무노이즈)이 보여주는 것보다 작다**(검토 1라운드 M1): 노이즈·2 mm 낙하·0.5 W 밀기 조건에서 1 kHz는 12 ms까지만 깨끗하고 13 ms부터 ±3° 13 Hz 한계 사이클, 15 ms 전복; 200 Hz는 15 ms까지, 20 ms 전복. 마찰 보상을 둘 다 꺼도 같으므로(13 ms 전복) 한계는 10 ms로 설계한 LQI6 루프 자체의 비선형 여유(+2~3 ms)이고, 보상의 피치 속도 게이트는 12 ms를 깨끗하게 만든다. 15번 기준값(≥ 25 ms)은 1 kHz 20 ms로 미달, 200 Hz 25 ms로 충족이며, 강건 여유(12/15 ms)를 함께 기록한다. 실기 루프 지연은 10 ms 안이어야 한다.
13. **지연선 준비 구간**: 시뮬 지연선이 첫 표본을 10번 반복하면 MCU의 정지 감시가 추정을 붙잡아(첫 틱의 1스텝 미분 속도 잡음 ±0.38 rad/s를 10 ms 유지) 1 kHz 10° 복귀 바퀴 피크가 1.38 Nm(> 1.36), 15° μ0.5 복귀가 공회전·전복으로 변했다. 반복 표본을 과거 시각으로 스탬프해 해결. 실기에서는 표본마다 시각이 전진하므로 생기지 않는다.
14. **타이어 condim**: 3(비틀림 마찰 없음)이 가장 낙관적이고 4가 접촉 패치를 반영한다. 9번 바퀴 rms 0.07 → 0.11 Nm 외에는 결과 차이가 작다.

## 4. 실패·미해결 항목의 원인과 선택지

### 4.1 16·17(IMU 바이어스 +1°, 페이로드 0.3 kg): 2 s 이후 최대 이탈 8.5~11.0 cm (기준 5 cm), 45/45회

놓은 뒤 2~4 s 동안 로봇이 6~7 cm 이동하며 새 평형(기울어진 몸체 또는 바뀐 무게중심)을 찾고, 이후 느린 왕복 ±2 cm가 겹친다. 이동량은 위치 루프의 강성(K_z1 ≈ 2.3 Nm/m)과 외란 모멘트(0.29 Nm 페이로드, 바이어스 1°에 대한 LQR 토크)로 정해지며 적분기 속도(z2·z3을 정지 중 3~10배 빠르게)로는 줄지 않았다. 강성을 더 올리는 조합(q_int 0.1~0.15, q_pos 0.3, q_v 0.3)은 모두 다른 필수 항목을 깨뜨렸다: 10° 기울기 바퀴 피크 1.45~1.53 Nm(> 1.36), μ0.5 15° 전복, 1 kHz 정지 불안정, 밀기 정착 3.2 s. 가장 가까운 조합(q_int 0.15·r_wheel 0.15·q_pos 0.2·r_hip 0.25)도 6.1~7.1 cm였다. 실제 피치는 두 항목 모두 수평에 가깝다(16번 평균 −0.01°, 17번 +0.4°: z2가 작동). **선택지(사용자 결정)**: (가) 16·17의 이탈 기준을 경사 정지(12)와 같은 10 cm로 두기(현 제어기 8.8~11.0 cm — 17번 최악 조합은 이것도 빠듯), (나) 실기에서 기동 시 무게중심·IMU 영점 보정 절차를 두어 이 두 외란을 제어기가 아닌 보정으로 제거, (다) 바퀴 모터를 2~2.5 Nm급으로 올려 위치 루프를 세게 할 여유 확보. 어느 쪽도 기준 수치를 임의로 바꾸지 않고 보고만 한다.

### 4.2 15번(지연 허용, 기록): 기준 시험 1 kHz 20 ms(미달)·200 Hz 25 ms, 강건 여유 12 / 15 ms

기준 시험(3° 기울기, 무노이즈, 정착)으로는 1 kHz 20 ms(1라운드 전 15 ms; 게이트 효과), 200 Hz 25 ms다. 검토 1라운드가 지적한 대로 이 시험은 큰 진폭의 한계 사이클을 보지 못한다: 노이즈·2 mm 낙하·0.5 W 밀기 조건에서는 1 kHz 12 ms, 200 Hz 15 ms까지만 깨끗하고 그 위에서는 13 Hz ±3° 진동 → 전복이다(2절 12). 마찰 보상을 꺼도 같으므로 LQI6 루프 자체의 여유(설계 지연 10 ms + 2~5 ms)다. 넓히는 방법은 r_hip 0.15(30 ms, 밀기 피치 +3°)나 10 ms 예측기(30 ms, 밀기 피치 2배)인데 둘 다 밀기 항목의 여유를 깎아 채택하지 않았다. 실기 루프 지연은 10 ms 안이어야 하며 측정 절차를 HANDOFF 2.1에 적었다.

### 4.3 3·6번 "포화 허용"의 해석(사용자 확인)

판정 코드는 "포화 허용" 항목에서 바퀴 피크 상한만 빼고 10 s 이동 rms 상한은 유지한다(보수적). 이번 라운드에는 6번이 통과해 판정을 바꾸지 않지만, 해석은 `합격기준.md` 6.2의 결정 항목으로 남겨 두었다.

## 5. 남은 과제

- 16·17의 사용자 결정(4절), 3·6번 "포화 허용" 해석, 15번 강건 여유의 기준 편입 여부(합격기준 6.2).
- 실기 전 확인(HANDOFF 2.1): IMU·관절 부호, 무장 해제 시작, 마찰 보상 0부터, 루프 지연 10 ms 안, qdd100 연속 토크(다리 rms 기준 4 Nm는 가정), 112 mm 타이어와 제자리 회전 바퀴 전류.
- 다리 길이 변화 중(웅크림) 주행과 큰 롤 외란은 시험 항목에 없다.
- 플랜트 파라미터는 MuJoCo 모델값이다. 실기 측정 후 `plan4_params.json`을 다시 만들면 게인 표가 자동으로 바뀐다.
