## 2. 모델 유도 검토 (`docs/plan4_model.md`, `plant_serial.py`, `serial_leg.py`, `upkie_params.py`)

### 2.1 유도의 수학적 타당성 — 정상

- **일반화 좌표**: q = (x, θ, φ). θ = 가상 다리(바퀴축→엉덩이) 각, +y 회전·엉덩이가 앞일 때 양; φ = 몸체 피치, −y 회전(= −IMU 피치). 엉덩이 p_h = (x + L0 sin θ, R + L0 cos θ), 몸체 COM = p_h + R_y(−φ)(b_x, b_z), 다리 COM = 바퀴축 + c(sin θ, cos θ) + d(cos θ, −sin θ). 모두 회전 규약과 일치한다(`plant_serial.py:66-68`).
- **운동 에너지**: 바퀴 ½(m_w + I_w/R²)ẋ², 다리 ½m_l|ṗ_l|² + ½I_l θ̇²(L0 고정 → 허벅지·종아리가 가상 다리와 강체 회전), 몸체 ½m_b|ṗ_b|² + ½I_b φ̇², 엉덩이 로터 ½J_h(θ̇ + φ̇)². 위치 에너지 V = g(m_l z_l + m_b z_b)(바퀴 높이 일정).
- **입력(가상일)**: 엉덩이 모터는 몸체–허벅지 사이 → δW = Tp(δθ − δψ_body) = Tp(δθ + δφ) ⇒ θ·φ 모두 +Tp. 바퀴 모터는 종아리–바퀴 사이 → δW = T(δx/R − δθ) ⇒ Q_x = T/R, Q_θ = −T(반작용은 다리만). 브리프의 "q_hip = θ + φ, 양쪽 +Tp, 다리에 −T"와 정확히 같다(`plant_serial.py:81`). 평행사변형 가정은 없다(5절 링크용 `plant6.py`를 쓰지 않음).
- **평형**: φ = 0, T = 0에서 ∂V/∂θ = Q_θ = Tp, ∂V/∂φ = Q_φ = Tp ⇒ m_l(d cos θ + c sin θ) + m_b(L0 sin θ + b_x) = 0(전체 COM이 바퀴축 위), Tp_eq = m_b g b_x = −0.314 Nm. 직접 다시 유도해 같은 식을 얻었다.
- **선형화**: E가 q에 무관하고 평형에서 q̇ = 0이므로 M(q_eq)δq̈ = −H_V δq − Dδq̇ + Eδu가 정확한 1차 근사다(코리올리 항은 2차, ∂V/∂q ≠ 0인 평형이지만 H_V로 선형화하는 것이 맞음). 단위 테스트가 비선형 deriv의 수치 미분과 A·B를 1e−6 수준으로 맞춘다.
- **정적 자세 적분 e_att = θ + φ + (Tp − T)/(gM)**: 정적 방정식 −gM δθ = −δT + δTp에서 정지 시 e_att = φ_true가 되고, IMU 바이어스는 θ + φ(= 엔코더의 몸체 기준 다리각)에서 상쇄된다. 수식이 맞고 결과도 일치한다(16번 실제 피치 평균 −0.006~−0.017°, 17번 +0.39°: 문서 1.3절과 같음). M(0.31) = 1.153 kg·m(문서 1.15).

5. **게인**: 문서 1.2절의 L0 = 0.31 게인(1 kHz·200 Hz, 8상태)이 실행 중 게인 표와 소수 둘째 자리까지 같다. 게인 표 범위 0.22~0.34 m가 MCU 다리 범위 0.24~0.335 m를 덮고 범위 밖은 끝값으로 고정(외삽 없음).
6. **참값 비사용**: MCU(`estimate`·`tick`), `LQI6Law`, 램프 호스트는 `obs["imu"]`·`obs["servo"]`만 읽는다(참값 키는 전달되지만 미사용: m13).
7. **관절 부호**: URDF 관절축 기반 `UPKIE_JOINT_SIGNS`(테스트로 확인)는 upkie v1/v2(left-wheeled) 관례와 맞다. anti-split(θ_L > θ_R → 왼쪽 Tp 감소), 요(+τ_yaw → 오른쪽 바퀴 전진 토크 증가 = 좌회전), 롤(+롤 → 왼쪽 다리 단축) 모두 음의 되먹임.
8. **호스트/MCU 경계**: 500 ms 타임아웃 → 단절 프로그램(속도·요 0, 자세 유지, 속도 모드 입력 0), `disconnect_off_s = 0`이라 모터 유지(기준 11번 "모터 OFF 없음"과 일치), 링크 복귀 시 재획득, FAULT(|피치| > 34°) 래치와 전 관절 무토크, `arm()`의 직립·측정·래치 조건, 패킷 deep copy.
9. **host_shaped 플래그(1단계 영향)**: 램프 호스트와 단절 프로그램의 `MotionCtrl.host_shaped`는 항상 False → `set_reference_shaping(True)`는 매 주기 no-op, 1단계 성형(램프 2 m/s², 전치필터 0.3 s, 적분 동결)만 쓰인다. z_att 게이팅(기준 가속도 저역통과 > 0.1 m/s²)은 1단계 결과에 포함되어 있다.
10. **문서 수치(맞는 것)**: 16·17번 실제 피치 평균(−0.01°, +0.39°), 200 Hz·1 kHz "가장 빠듯한 통과 지표"들, M(0.31) = 1.153 kg·m, F_ff = 18.18 N/다리, 밀기 힘 스케일, 원기둥 타이어에서 9번 0.25 Nm 실패.
11. **그 밖의 확인**: 7번(1.0 W)은 9조합 모두 생존, 4·7번 시드 1~4 생존, 3초 순항 뒤 링크 끊김도 통과, 끝점→최대 이탈로 바꿔도 판정 불변(m2).

## 6. 권고 (우선순위)

1. **실기 전 필수**: M1(마찰 보상·속도 창 재설계 후 수평 시작 + 낙하/밀기 + 노이즈 조건의 지연 여유 재측정), M2(입력 검증·적분기 보호·NaN → FAULT), M3(IMU 어댑터와 실기 관례 단위 테스트), m12(무장 해제 시작·데이터 감시·들림 감지).

3. **판정 코드 보강**(현재 판정은 바뀌지 않음): m3(정지형 alive), m1(생존 시드 0~4), m2(최대 이탈), m4(최소 유지), m5(순항 후 끊김), m6(모터별 rms·바퀴별 포화), m8(캐시 해시), n7(15번 μ).

5. **사용자 결정 필요**: m7(3·6번 "포화 지속만" 해석), 15번 보조 기록 지표 추가 제안(M1), 6·16·17 실패의 선택지(문서 4절, M4 반영 후).
