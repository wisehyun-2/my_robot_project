# 단계별 통과 시험 (MPC)

`v5_lqi/TEST`와 같은 시나리오·지표·기준으로 MPC를 시험한다. 공통 코드는 `wbr/bench/stage_tests.py`다.
환경 변수, 기준표, 턱 모양, 합격기준.md와 다른 점은 `v5_lqi/TEST/README.md` 2·3·4절을 그대로 따른다. 여기에는 다른 점만 적는다.

## 1. 단계

LQI 폴더와 같이 전체 제어기 하나만 시험한다(`v5_mpc/controller.py`의 `STAGES`: `mpc_kwargs`의 `q_att=0.2, q_pos=0.5`, 시험 파일 `test_stage4_int_tilt.py`). 적분 상태가 LQR 대신 MPC의 예측 모델에 들어간다는 점만 다르다.

## 2. 실행 (`wheeled_biped/`에서)

```
python v5_mpc/TEST/run_stages.py --stage 4 --keep-going
```

전체 MPC(단계 4)만 쓴다. 보고서는 `v5_mpc/TEST/results/stage_report.md`와 `.json`에 덮어쓴다. 시드 하나에 4~6분 걸린다.

## 3. 결과 (단계 4, 시드 0, 1 kHz, 지연 10 ms, 링크 25 cm)

11-11에 만든 보고서의 값이다(4·5절의 수정 뒤, MPC는 시드 0만). LQI8 값은 같은 날 LQI 보고서의 시드 0이다. 두 보고서는 11-14 코드 정리 전 것이라 11-15에 지웠고, 다시 만들어야 한다(`v5_lqi/TEST/README.md` 6절).
기준을 넘은 판정은 288건 중 LQI8 8건(시험 5개), MPC 9건(시험 7개)이다. 넘어짐·무릎 꺾임은 둘 다 없다. ✗는 기준 초과다.

- 속도 추종은 MPC가 빠르고, 그만큼 몸통이 더 기운다. 1-4(속도 스텝 0.5 m/s)에서 90 % 도달 1.31 → 0.90 s, 정지 뒤 정착 2.13 → 1.00 s, 피치 피크 1.16 → 2.03°다(LQI8 → MPC, 모두 기준 안).
- 정지(1-1), 기울기 복귀(1-2), 밀기(1-3)는 두 제어기가 거의 같다. MPC만 넘는 것은 2-14와 2-15다. 2-15는 기준을 0.5 % 넘고, LQI8도 4.99로 기준에 붙어 있다.
- 2-3, 2-9, 2-10, 2-12, 2-13의 롤은 LQI8도 넘는다. 바깥 루프 쪽 원인이다(`v5_lqi/TEST/README.md` "링크 25 cm 결과").
- 11-15 노트북에서 시드 0을 다시 돌렸을 때(저장하지 않음)도 MPC는 같은 9건이 넘었다(값은 조금 다르다).

## 4. 2-19(과속방지턱 20 cm)의 피치 10.1°: 원인과 수정 (11-11)

- 원인: 토크 제약(`MpcLaw.limits`)이 무릎에 이미 실린 토크를 정적 지지력만으로 작게 잡았다. 다리가 범위 끝에 닿으면 이미 넘은 제약을 지키려고 hip 균형 토크를 막았다.
- 수정: MCU가 매 주기 다리별로 준 힘(정적 지지력 + 길이 PD + 롤 + 범위 벽 + 감쇠)을 `DiabloMcu.leg_force_cmd`에 남기고, `MpcLaw.limits`가 한 주기 전의 그 값을 쓴다.
- 결과(시드 0): 피치 최대 10.11° → 1.58°, QP 호출 564 → 46회. 11-11 보고서에서는 1.59°다(LQI8 1.54°, 기준 ≤ 5°).

## 5. 2-20(턱 위 속도)과 2-13(옆 이동): 원인과 수정 (11-11)

- 원인: 고르지 않은 바닥에서 MCU가 속도를 줄일 때 넘기는 기울임 값 `v_lean`을 `MpcLaw`가 쓰지 않아 감속이 약했다(감속도 최대 0.33, LQI8은 0.60 m/s²).
- 수정: `MpcLaw.compute`가 `LQI8Law`와 같은 식으로 다리 기울기 목표를 옮긴다(`theta -= v_lean · 기준 가속도 / g`). 감속 명령의 선행(0.15 s)은 그대로 두었다.
- 결과(시드 0): 2-20 턱 위 속도 0.316 → 0.180 m/s(기준 ≤ 0.3), 2-13 옆 이동 18.97 → 16.93 cm(기준 ≤ 17.5). 대신 2-15 다리 토크 rms가 4.98 → 5.03 N·m로 기준을 넘게 됐다.
