# 단계별 통과 시험 — LQR 먼저, 적분은 나중에

균형 제어기를 한 번에 완성하지 않고 **순수 LQR → 바깥 루프 → ∫위치 → ∫기울기** 순서로 올리기 위한 시험이다.
한 단계를 통과한 뒤 다음 단계로 넘어가고, 뒤 단계는 앞 단계의 시험을 전부 다시 통과해야 한다.

대상 로봇은 v5 CAD 로봇(`robot_cad_v5/calc/mass_properties.json`, AKE60-8 × 6, 10.97 kg)이고 MuJoCo 폐루프로 돌린다.
시나리오와 측정 정의는 기존 합격 판정(`docs/합격기준.md`, `wbr/bench/acceptance.py`)의 것을 그대로 쓴다.
기존 단위 테스트(`tests/`)와는 별개다.

## 1. 단계

| 단계 | 균형 제어기 | `lqi_kwargs` | 이 단계에서 확인하는 것 | 파일 |
|---|---|---|---|---|
| 1 | 순수 LQR, 상태 6개 `[θ, θ̇, v − v_ref, φ, φ̇, x − x_ref]` | `q_att=None, q_pos=None` | 상태 피드백만으로 서고, 기울기·밀기에서 복귀하고, 속도 스텝을 따라간다 | `test_stage1_lqr.py` |
| 2 | 단계 1과 같음 | 같음 | 논문 Fig. 6의 나머지 네 제어기(높이, 요, 롤, 다리 벌어짐)가 균형을 해치지 않고 제 일을 한다 | `test_stage2_outer_loops.py` |
| 3 | + ∫위치 (z3) | `q_att=None, q_pos=0.5` | 일정한 외란 아래에서 출발 위치로 돌아온다. 단계 1·2 시험 재통과 | `test_stage3_int_position.py` |
| 4 | + ∫기울기 (z2) = 현재 제어기 | `q_att=0.2, q_pos=0.5` | 일정한 외란 아래에서 실제 몸통이 수평으로 돌아온다. 단계 1·2·3 시험 재통과 | `test_stage4_int_tilt.py` |

상태 6번째(`x − x_ref`)는 코드에서 `z1 = ∫(v − v_ref)`다. 속도를 적분한 값이라 위치 그 자체이고 논문의 `x` 상태에 해당한다.
논문의 `∫x`가 z3, `∫γ`가 z2다. 코드에서는 `Plan4Config(lqi_kwargs={...})`에 위 값을 넣으면 그 단계가 된다.

## 2. 실행

`wheeled_biped/`에서 실행한다.

```
python TEST/run_stages.py                    # 단계 1 → 4, 실패한 단계에서 멈춤. 보고서: TEST/results/stage_report.md
python TEST/run_stages.py --stage 1 2        # 일부 단계만
python TEST/run_stages.py --keep-going       # 실패해도 끝까지
python -m unittest discover -s TEST -v                            # unittest로 전부
python -m unittest discover -s TEST -p "test_stage1*.py" -v      # 한 단계만
```

전체 약 2분 30초(단계 1: 45 s, 2: 6 s, 3: 45 s, 4: 47 s).

| 환경 변수 | 기본 | 뜻 |
|---|---|---|
| `WBR_TEST_SEEDS` | `0` | 노이즈 시드 목록, 예 `0,1,2,3,4` |
| `WBR_TEST_LATENCY_MS` | `10` | 센서 → 토크 지연 |
| `WBR_TEST_RATE` | `1000` | 제어 주기 [Hz] (200도 가능) |
| `WBR_TEST_LONG` | `0` | `1`이면 정지 시험을 합격 기준대로 60 s (기본 30 s) |
| `WBR_TEST_CAD` | v5 | 다른 CAD 버전의 `mass_properties.json` 경로 |

PowerShell 예: `$env:WBR_TEST_SEEDS = "0,1,2"; python TEST/run_stages.py`

## 3. 통과 기준

공통 조건: 센서 노이즈 켬, 지연 10 ms, 1 kHz, 판정 피치는 시뮬레이터의 실제 몸통 피치.

모든 시험에 함께 붙는 기준: 넘어지지 않음, 무릎이 완전 신장 반대쪽으로 넘어가지 않음, 완전 신장까지 5 mm 이상,
바퀴·hip·무릎 토크 피크 ≤ 10 N m(AKE60 피크의 80 %), hip·무릎 rms ≤ 5 N m(정격), 바퀴 10 s rms ≤ 2.5 N m.

| 시험 | 시나리오 | 기준 | 출처 |
|---|---|---|---|
| 1-1 | 정지 30 s | 20 ms 이동평균 \|피치\| ≤ 1°, rms ≤ 0.5°, 드리프트 ≤ 5 cm | 합격기준 1번 |
| 1-2 | 초기 기울기 10° | 정착 ≤ 2 s, 이동 ≤ 0.3 m | 2번 |
| 1-3 | 밀기 0.5 W(무게의 절반), 0.1 s | 정착 ≤ 3 s, 피치 피크 ≤ 8°, 이동 ≤ 0.5 m | 5번 |
| 1-4 | 속도 스텝 0 → 0.5 m/s(2.5 s) → 0 | 90 % 도달 ≤ 1.5 s, 오버슈트 ≤ 20 %, 정상 오차 ≤ 0.05 m/s, 피치 ≤ 5°, 정지 뒤 이탈 ≤ 0.5 m, **정지 뒤 정착 ≤ 3 s** | 8번(정착 시간은 4절 참고) |
| 1-5 | 경사 5° / IMU 오차 +1° / 앞쪽 짐 0.5 kg 정지 30 s | 넘어지지 않음. 남는 위치 오프셋과 기울기를 **기록**(안전 한계 15 cm, 2.5°) | 이 폴더 |
| 2-1 | 4 cm 웅크림 후 복귀 | 피치 ≤ 3°, 복귀 후 정착, 다리 길이 오차 ≤ 3 mm | 10번 + 길이 오차 |
| 2-2 | 요 1 rad/s, 2 s | 마지막 1 s 평균 오차 ≤ 10 %, 피치 ≤ 2° | 9번 |
| 2-3 | 롤 기준 3° | 마지막 1 s 평균 오차 ≤ 0.5°, 피치 ≤ 2° | 이 폴더 |
| 2-4 | 0.5 m/s로 가며 1 rad/s 회전, 정지 | 요 오차 ≤ 10 %, 좌우 다리각 차 ≤ 5°, 피치 ≤ 5°, 정지 뒤 정착 ≤ 3 s | 이 폴더 |
| 3-1~3 | 경사 5° / IMU 오차 +1° / 앞쪽 짐 0.5 kg 정지 30 s | **마지막 5 s 평균 위치가 출발점에서 3 cm 이내**, 최대 이탈 ≤ 10 cm | 12·16·17번의 10 cm + 이 폴더 |
| 4-1~3 | 같은 세 외란 | **마지막 5 s 평균 실제 피치 ≤ 0.5°**, 흔들림 rms ≤ 0.5° | 이 폴더 |

기준 숫자는 `stage_common.py`의 믹스인 클래스와 맨 위 상수에 모여 있다.

## 4. 합격기준.md와 다른 점

- **모터 한계**: upkie의 qdd100·mj5208 대신 AKE60-8(피크 12.5, 정격 5 N m). 포화 지속·관절 속도 기준은 넣지 않았다.
- **정지 시험 길이**: 기본 30 s(합격 기준은 60 s). `WBR_TEST_LONG=1`로 60 s.
- **속도 스텝의 정지 뒤 정착**: 합격 판정은 정지 뒤 3 s만 돌리고 마지막 위반이 끝 1 s 안이면 미정착이라, 사실상 2 s 안에
  정착해야 한다. v5는 정지할 때 25~29 cm 나갔다가 0.13~0.16 m/s로 되돌아와 **2.1~2.2 s**가 걸린다(세 단계 모두). 이 시험은
  정지 뒤 5 s를 돌리고 정착 시간 ≤ 3 s로 판정한다. 2 s로 맞추려면 제어기를 조정해야 한다(결정 사항).
- **짐**: 0.5 kg(합격 기준 17번은 5.3 kg upkie에 0.3 kg). 로봇 질량 비로 키웠다.
- **16·17번의 피치 기준**: 합격 기준은 전 구간 이동평균 ≤ 1°다. 여기서는 적분 두 개의 역할을 따로 보려고 끝 5 s 평균을 쓴다.
- **변동 매트릭스 없음**: 질량 ±15 %, 마찰 0.5~1.0 조합은 돌리지 않는다(공칭만). 시드는 기본 0 하나.
- **추가 항목**: 무릎 꺾임과 완전 신장 여유(전 시험), 롤 기준, 주행 중 회전.

## 5. 현재 측정값 (시드 0~4의 범위, 2026-11-06)

| 시험 | 단계 1·2 (순수 LQR) | 단계 3 (+ ∫위치) | 단계 4 (+ ∫기울기) |
|---|---|---|---|

| 1-2 정착 | 0.4~1.5 s | 1.7 s | 1.7 s |
| 1-3 정착 / 피치 피크 | 2.2 s / 3.1~3.4° | 2.0 s / 3.9° | 2.1 s / 3.4° |
| 1-4 도달 / 오버슈트 / 정상 오차 / 정지 뒤 정착 | 1.30~1.33 s / 12~13 % / 0.042~0.043 / 2.20~2.22 s | 1.25~1.28 s / 12 % / 0.043~0.044 / 2.07~2.10 s | 1.27~1.28 s / 11~12 % / 0.041~0.042 / 2.06~2.09 s |
| 2-1 다리 길이 오차 | 0.6 mm | 0.5~0.7 mm | 0.5~0.7 mm |
| 2-2 요 오차 | 1.4 % | 1.3~1.4 % | 1.4 % |
| 2-3 롤 오차 | 0.12~0.13° | 0.11~0.12° | 0.11~0.13° |
| 2-4 좌우 다리각 차 | 3.6° | 3.6° | 3.6° |
| 경사 5°: 위치 / 기울기 / 최대 이탈 | 2.1~2.5 cm / 0.94~0.98° / 7.8~8.0 cm | **1.5~1.6 cm** / 0.90~0.91° / 4.3~4.5 cm | 1.3~1.4 cm / **0.00~0.02°** / 4.4~4.5 cm |
| IMU 오차 +1°: 위치 / 기울기 / 최대 이탈 | 8.7~9.2 cm / 1.36~1.46° / 11.7~11.8 cm | **0.4~0.5 cm** / 1.45~1.47° / 7.8~7.9 cm | 0.0~0.1 cm / **0.00~0.01°** / 7.5~7.6 cm |
| 앞쪽 짐 0.5 kg: 위치 / 기울기 / 최대 이탈 | 8.3~8.6 cm / 0.86~0.88° / 11.5~11.6 cm | **0.2 cm** / 0.93~0.96° / 7.3~7.5 cm | 0.3~0.4 cm / **0.35~0.37°** / 7.1~7.3 cm |

- 순수 LQR은 균형 시험(1-1~1-4)과 바깥 루프 시험(2-1~2-4)을 모두 통과한다. 일정한 외란에서만 위치 8~9 cm, 기울기 1°
  안팎이 남는다(1-5가 이 값을 기록한다).
- ∫위치는 위치만, ∫기울기는 기울기만 고친다. 경사는 다리가 기울어 유지 토크를 만들기 때문에 ∫위치 없이도 위치 오프셋이 작다.
- 여유가 가장 작은 지표: 1-4 정상 오차 0.043 / 0.05, 1-3 hip·무릎 피크 8.5 / 10 N m(단계 3), 최대 이탈 7.9 / 10 cm.

### 시험이 실제로 걸러내는가

적분을 켜지 않은 제어기에 적분 단계 시험을 걸면 실패한다(확인함).

| 시험을 건 제어기 | 시험 | 결과 |
|---|---|---|
| 순수 LQR | 3-2, 3-3 (IMU 오차, 짐: 위치) | 실패 — 위치 8.9 / 8.3 cm (기준 3), 최대 이탈 11.7 / 11.5 cm (기준 10) |
| 순수 LQR | 3-1 (경사: 위치) | 통과 — 2.5 cm. 경사는 ∫위치를 가려내지 못한다 |
| LQR + ∫위치 | 4-1, 4-2, 4-3 (기울기) | 실패 — 0.91 / 1.47 / 0.95° (기준 0.5) |

## 6. 실패했을 때

| 실패 | 먼저 볼 것 |
|---|---|
| 단계 1의 1-1, 1-2 | 플랜트 파라미터(`plan4_params.json`), 관절 부호, IMU 방향. 게인이 아니라 모델이 틀린 경우가 많다 |
| 1-3, 1-4 | LQR 가중치(`q_v`, `r_wheel_frac`, `r_hip_frac`), 속도 기준 성형(램프 2 m/s², 필터 0.3 s) |
| `knee_flipped`, `leg_margin_mm` | 다리 길이 PD가 로봇 무게에 비해 무르다(`kp_leg`, `kd_leg`). 몸통 질량 비로 환산한다 |
| 2-2, 2-4의 요 오차 | 요 PI(`kp_yaw`, `ki_yaw`). 제어 대상 이득 W / (2 R I_zz) 비로 환산한다 |
| 2-4의 다리각 차 | 다리 벌어짐 PD(`kp_split`, `kd_split`) |
| 단계 3·4에서 1-x가 새로 실패 | 적분 가중치가 너무 세다(`q_pos`, `q_att`는 클수록 약하다) |
| 3-x 위치, 4-x 기울기 | 적분 한계(`pos_limit`, `att_limit`)에 걸렸는지, 기준이 움직이는 동안의 적분 동결이 풀리는지 |

## 7. 실기에서

같은 순서로 올린다. 단계 1의 `lqi_kwargs`로 시작해 시험 1-1~1-4를 실물로 반복하고, 통과하면 바깥 루프, 그다음 적분을 하나씩 켠다.

- 실기에는 "실제 피치"가 없다. IMU 추정 피치만 있으므로 4-2(IMU 오차)는 실물에서 직접 볼 수 없다. 수평계를 몸통에 올리거나,
  짐(4-3)과 경사(4-1)로 확인한다.
- 위치는 바퀴 오도메트리로 잰다. 바닥에 출발선을 표시해 두면 3-x를 눈으로도 확인할 수 있다.
- 요·다리 길이 게인은 이 시뮬레이션과 같은 환산값을 MCU 설정에 넣어야 한다(`ake_cad.outer_loop_gains`).
